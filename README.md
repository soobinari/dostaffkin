# Dostaffkin

Веб-приложение для оформления и отслеживания доставки посылок между странами и внутри стран.

## Возможности

- расчёт маршрута и стоимости доставки по адресам на Яндекс.Картах;
- выбор размера посылки: от `XS` до `MAX`;
- выбор обычной или приоритетной доставки;
- оформление заявки с контактными данными и комментарием;
- получение номера отправления после создания заявки;
- отслеживание отправления по номеру и просмотр маршрута со статусами;
- уведомления об ошибках и успешных операциях.

## Маршруты и API

- `/` — главная страница;
- `/order` — расчёт и оформление доставки;
- `/track` — отслеживание отправления;
- `POST https://testologia.ru/delivery/create` — создание заявки;
- `GET https://testologia.ru/delivery/info?id={id}` — получение информации об отправлении.

Расчёт использует расстояние маршрута, тариф размера посылки и минимальную стоимость. Данные карт и подсказки адресов подключаются через внешний скрипт Яндекс.Карт.

## Технологический стек

- TypeScript;
- Angular `21.1.1` (standalone-компоненты, Router, Reactive Forms);
- RxJS `7.8.2`;
- `ngx-toastr` для уведомлений;
- Яндекс.Карты для геокодирования, подсказок адресов и построения маршрутов;
- npm `10.9.2`, Angular CLI, TypeScript `5.9.3`, Vitest.

База данных и собственный backend в проекте отсутствуют: приложение обращается к внешнему API.

## Установка и запуск

Требуется Node.js и npm.

```bash
npm install
npm start
```

После запуска приложение доступно по адресу `http://localhost:4200/`.

## Команды

```bash
npm start   # dev-сервер
npm run build # production-сборка в docs/
npm run watch # сборка в режиме наблюдения
npm test    # запуск unit-тестов
```
